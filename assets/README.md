# Fox

`fox.glb` is the Khronos glTF Sample Assets Fox, embedded unchanged.
Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox

- Model: PixelMannen, CC0 1.0 (2014).
- Rigging and animation: tomkranis, CC BY 4.0 (2014).
- glTF conversion: AsoboStudio and scurest, CC BY 4.0 (2017).

https://creativecommons.org/publicdomain/zero/1.0/
https://creativecommons.org/licenses/by/4.0/

The Run skeletal clip is sampled using the music clock. Stage translation adds
an application-generated jump arc between consecutive note platforms.
